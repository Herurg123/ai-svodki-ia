## Решение и ограничения

**Первый контрольный день демонстрирует значительное преимущество Sol
в ширине первичного accepted pool (14 против 5)**, включая
проверенные крупные Legora и Amp. **Однако** PHP2Shell отсутствует у Sol,
а часть Sol-only не прошла независимый source freshness proof;
Sol не проверялась как Editorial и не проводила end-to-end публикацию.
Нельзя автоматически переходить с Terra на Sol по этой таблице.
Отдельная проверка первоисточников выявила минимум **один доказанный
outside-window Sol Primary** (исследование Anthropic от 20.10, ошибочно
переатрибутированное по статье TechRadar 22.10) и один **недоказанный
датированный как новый релиз** (VS Code 1.143 Insiders, официальный
changelog обновлён 15.10). Поэтому `Sol-only = 11` является числом
*принятых валидатором*, а не гарантированных пригодных новых событий.
Проблему следует разбирать как model-source-freshness / downstream proof,
а не приписывать победу по одному количеству.

Результат 22 октября дал противоположную картину по числу кандидатов,
поэтому особенно важен **повторный контрольный день 24 октября**
с новой заморозкой pre-release Terra, независимым Sol 12/12, отдельным
учётом расходов и оценкой event-level свежести.
Владелец разрешил убрать долларовый stop-guard на 23–24 октября, но
каждый API запрос и затраты необходимо учитывать. Новые запросы
**не запускать автоматически**. PR #214 черновой, не merge.
После успешного run 39908841706 одноразовый paid job удалён из branch
CI; никакой production code не менялся.
