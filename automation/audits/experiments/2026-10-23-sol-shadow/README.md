## Что делает ручной job

- Сначала стандартные офлайн CI-тесты, затем one-shot контроль предыдущих
  запусков через API GitHub до доступа к ключу OpenAI.
- Скачивает исходный checkpoint Terra (не подменяя содержимое). В локальном
  checkout воссоздаёт исторический архив до выпуска 23 октября.
- Фиксирует `gpt-6.1-sol / medium`, один Web Search на направление,
  до 12 направлений, без автоматических retry.
- Записывает **каждый** raw API output, usage, response ID, запрос, provider
  tier, поиск и отклонения до перехода к следующему направлению. Остановка
  на сбое или бюджете сохраняет частичные результаты.
- Бюджетная оценка до $1: `incentivized-tier` предполагает бесплатные
  текстовые токены на основании биллинга 19–22 октября, `default` оценивается
  по публичному Standard-прайсу. Это клиентский guard, **не лимит OpenAI**.
  При all-default попытка может остановиться до 12/12. Учитывать неопределённый
  расход при transport failure. Если сработает guard, не запускать заново.
- Сверяет 12/12 и формирует `ab-review.csv/json`, но **совпадение URL не
  равно совпадению события**.
- Загружает архив в Actions даже при ошибке. Никакой публикации.

## Решение после прогона

Оценивать независимые *события*, а не количество URL: свежесть первого
публичного анонса, вес события, первоисточники, значение для России и Азии,
модельные пропуски отдельно от `legal_scale` и схемных отклонений. Если Sol
существенно выигрывает в этом сравнении, рассмотреть миграцию; при равном
результате оставить Terra; при взаимодополнении рассмотреть дополнительный
Sol catch-up. Два последовательных дня не означают автоматической замены.

Оригинальный Research artifact хранится в Actions до **6 ноября 2026**.
Новый paid job будет удалён из этой экспериментальной PR-ветки после анализа
сохранённого запуска. `main` не меняем.
