# A/B Terra 5.6 vs Terra 6.1: сохранённые результаты и стоимость (28.10.2026)

**Состояние:** оба исходных прогона выполнены, доказательства сохранены; независимая фактологическая оценка всех событий ещё не завершена. **Решение:** сохранить `gpt-5.6-terra` в production по текущей фактической цене. Замена на 6.1 не разрешена.

Оба ZIP получены **оригинальными** из GitHub Actions, не реконструированы из финального JSON; SHA-256 сравнены с оригинальными digest GitHub. Содержимое ZIP не включено целиком в публичный git (Terra 5.6 содержит десятки мегабайт бинарных объектов); сами downloadable ZIP ограничены retention GitHub Actions. Для долгосрочной инспекции в git зафиксированы результаты поиска, первоисточники, финансовые строки без идентификаторов, хеши и ссылки. Полный ZIP необходимо хранить отдельно после истечения Actions retention.

**Честное ограничение манифеста 6.1:** из 97 файлов, заявленных в `terra61-shadow-manifest.json`, ровно 96 присутствуют в original ZIP и совпадают по SHA-256. Отсутствует скрытый runtime `automation/fixtures/research/.runtime/primary-recall-research-2026-10-28.json` (не включён `actions/upload-artifact` по умолчанию); это не повод подменять ZIP новой сборкой. Сами файлы Research, Primary, редактура и Coverage в ZIP присутствуют.

**Окно и происхождение:** обе модели использовали один source prepublication SHA `eabe4855b7d604c4947f5c9f47df694a76be7680` и точный Primary window `2026-10-26T05:05:28+03:00` — `2026-10-28T05:06:35+03:00`. Но snapshot manifest до платного выполнения 5.6 отсутствовал, поскольку штатная сводка была опубликована через `workflow_dispatch` раньше scheduled event. Для manual 6.1 он реконструирован из неизменённого source commit **после факта**, с явной маркировкой retrospective. Исходный 5.6 ZIP и сохранённые временные границы не менялись. Web Search выполнялся в разные часы: результаты индекса могли измениться.

## Действующее решение о льготе

**Сохранить `gpt-5.6-terra` и штатные параметры в production.** По фактическому учёту на 28 октября её текстовые токены целиком попали в `incentivized-tier`; $0.38134 за штатный выпуск относятся к платному Web Search ($0.25 за 25 поисков) и image GPT Image 2 ($0.13134). Программа льготных токенов **не покрывает Web Search**, поэтому нулевая стоимость токенов не означает бесплатный конвейер.

Проверенный 28.10.2026 официальный список: https://help.openai.com/en/articles/10306912-sharing-feedback-evaluation-and-fine-tuning-data-and-api-inputs-and-outputs-with-openai

В нём **явно перечислена `gpt-5.6-terra` в группе 10M/2.5M** и **пока не перечислена `gpt-6.1-terra`**. Однако 3 фактических вызова 6.1 в пользовательском CSV помечены `incentivized-tier`: это наблюдение, а не доказательство включения всей модели в публичную программу. Следить за обновлением официального списка, настройкой Data Sharing (статус enrollment) и за колонкой `service_tier` по модели в https://platform.openai.com/usage/chat-completions; учитывать задержку отражения Usage/Costs.

Не менять модель автоматически при обновлении списка. Сначала отдельно проверить **полную фактическую стоимость реального конвейера** и качество новостей. Дата окончания программы для Terra 5.6 не обещана.
