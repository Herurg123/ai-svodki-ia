# Step 4: saved-evidence comparison protocol

Status: pre-execution protocol for deterministic development A/B. It is not
Terra search acceptance or final independent architecture approval.

Baseline: b474b06bc00f365b9737ece4dd0912c1892489e7. Proposal: current dedicated
step-4 branch. Each version runs in an isolated subprocess. Network is forbidden.
The exact Sep-5 run/artifact IDs and SHA-256 are in
`source-resolution-daybreak-2026-09-05.json`; current OpenAI HTML/RSS extracts
are separately identified, never presented as part of that historical artifact.

Expected changes, fixed before running this replay:

1. The historical Daybreak candidate remains excluded after the original Axios
   403. Its exact title, cited URL, source failure and event-date evidence reach
   the existing resolution prompt in the proposal; baseline has no such lead.
2. Historical `outside_window` rejections remain diagnostics unless exact aware
   evidence contradicts the rejection. The three obsolete Sep-5 leads must not
   take mandatory resolution priority. Existing strong `unverified` priority
   and the six mandatory Coverage directions remain unchanged.
3. A **controlled, manually supplied** alternative candidate using the known
   official article can pass Source Freshness via exact URL RSS timestamp plus
   agreeing visible article date. This proves a deterministic handoff, not that
   Terra will discover or choose the alternative. The original excluded row is
   never directly resurrected. Archive/editorial remain downstream gates.
4. Wrong article/host/redirect, conflicting/ambiguous/missing RSS metadata,
   generic stale metadata and stale event controls stay fail-closed.
5. Across empty/sparse/normal/dense pools, three regions, fresh/stale/undated/403
   sources and reversed ordering, unaffected complete candidate payloads and
   source-gate diagnostics must match baseline, except the new saved pre-gate
   diagnostic snapshot. No source calls may occur for a reliable stale event.
6. A spent or indeterminate seventh slot must never be stripped by quality
   migration. Interruption reservation must be saved before transport; replay
   with or without surviving evidence files must issue zero replacement calls.
   Baseline's old 7-to-6 migration is the intentional corrected difference.
7. Recovery diagnostics must come from the selected artifact lineage and exact
   window; sibling runs are never borrowed. Copying these records performs no
   polling. Existing full-artifact recovery is not forcibly downgraded.
8. No new Coverage invocation is forced on an otherwise skipped full-digest
   path. Existing bounded seventh-slot priority can replace agency corroboration
   when a strong unresolved lead exists, as in the pre-existing quality policy.
   Dense candidate-cap behavior and publication quotas are not broadened.

Required remaining admission gates: actual assistant-side Terra search A/B and
an independent architecture assessment of priority, overlap, caps, Coverage
entry/recovery and prompt/schema overhead. Do not create a production PR or
merge merely because this deterministic replay and the unit suite pass.
