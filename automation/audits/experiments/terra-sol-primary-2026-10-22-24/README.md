- Прежние experimental CI jobs уже удалены из экспериментальных веток; здесь нет активируемых workflow.
- Не запускать `run_shadow.py`, `run_primary.py`, `resume_four.py` на платном API без отдельного санкционированного бюджета.
- Оригинальные PR #213–215 можно закрывать **после** архивирования и независимой сверки. Их ветки удаляются отдельно, без merge.

## Оценка конфиденциальности перед публикацией исходных ZIP

Проверка 26 октября 2026: распакованы и прочитаны все восемь оригинальных
Actions ZIP. По содержимому выполнен поиск типичных OpenAI/GitHub/AWS/Google/Slack
ключей, JWT, Authorization/Bearer headers, приватных SSH/PEM ключей,
именованных JSON-полей с паролями, секретами, cookies и access/refresh tokens,
email-адресов и подписанных URL. Очевидных действующих учётных данных и
типичных персональных идентификаторов **не обнаружено**. Ложноположительное
совпадение с префиксом `sk-` относилось к slug публичного URL статьи.

**Ограничение:** это статическая проверка известных шаблонов, а не
криптографическое доказательство отсутствия всех возможных секретов.
Исходные ZIP включают сырые ответы API, внутренние рабочие промпты,
журналы usage, response/request IDs, диагностические сообщения и исторические
данные конвейера. Публичная публикация раскрыла бы эти сведения навсегда,
в том числе через Git history после удаления файла.

Владелец **явно разрешил публичную публикацию** восьми оригинальных ZIP
26 октября 2026 года. После этого исходные архивы включены в каталог
[`originals/`](originals/) без модификации байтов, а ZIP-хэши и Git blob SHA
сверены с локально скачанными оригиналами. Оценка конфиденциальности выше
фиксирует ограничения и не гарантирует отсутствия всех возможных чувствительных
сведений.
