# Retrieval baselines

Этот каталог хранит manifests постоянных контрольных точек retrieval-архитектуры.

Каждый baseline должен указывать точный commit SHA и отдельную `archive/*` ветку.
Существующий baseline нельзя переписывать или переиспользовать под новую версию:
для следующего крупного изменения создаётся новый manifest и новый указатель.

Текущий pre-hybrid baseline:

- `2026-08-09-pre-hybrid.md`;
- `archive/search-baseline-pre-hybrid-2026-08-09`;
- `d926a3abf8b9443f58f303d984ef79fdc289fc3e`.
