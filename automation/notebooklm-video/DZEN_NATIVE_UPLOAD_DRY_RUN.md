# Нативная загрузка видео в Дзен: безопасный dry-run

Этот документ описывает **экспериментальный** browser-upload путь для уже готового
NotebookLM MP4. Он не подключён к `worker.js`, `run-worker.cmd` или Планировщику
Windows и не нажимает финальную кнопку «Опубликовать».

Цель первой реализации — воспроизвести подтверждённый вручную сценарий в том же
защищённом профиле Яндекс.Браузера и остановиться в состоянии готового video draft.

## Подтверждённый ручной сценарий 27.08.2026

На канале «Заметки из подпространства» проверено:

1. Дзен-студия открывается в защищённом профиле Яндекс.Браузера.
2. Кнопка создания публикации открывает меню с пунктом «Загрузить видео».
3. Локальный MP4 выбирается через стандартный file input.
4. После выбора MP4 создаётся URL с `videoEditorPublicationId`.
5. Форма «Публикация видео» содержит название, описание, обложку, теги и
   настройку «Кто может комментировать».
6. Локальный PNG принимается как пользовательская обложка без обязательного
   дополнительного кадрирования.
7. После обработки Дзен показывает «Загрузили и обработали видео» и активирует
   кнопку «Опубликовать».
8. Ручная публикация этим путём появилась именно в разделе **«Видео»**.

Это является текущим эталонным UI-сценарием. RSS-путь для нативного Video ранее
закрыт как неуспешный, см. `DZEN_VIDEO_EXPERIMENTS.md`.

## Реализованный dry-run

`dzen-publish.js`:

- запускается только с явным `--dry-run`;
- берёт выпуск из `state.json` по дате;
- использует `job.downloadedFile` как локальный MP4;
- использует `job.previewFile` или соседний PNG; если PNG отсутствует, создаёт его
  через уже установленный `ffmpeg-static`;
- подключается к уже запущенному роботизированному Яндекс.Браузеру по CDP либо
  запускает тот же `browserExecutable` с тем же `browserProfile`;
- проверяет, что открыта авторизованная Дзен-студия нужного канала;
- выбирает «Загрузить видео»;
- передаёт MP4 через Playwright file chooser;
- сохраняет `videoEditorPublicationId` и draft URL в `state.json`;
- заполняет название и описание;
- загружает локальный PNG через «Добавить обложку»;
- добавляет ровно пять тегов и после каждого подтверждает появление отдельной
  tag-chip; при необходимости кликает точную подсказку из popup;
- особенно проверяет, что пятый тег действительно стал отдельной плашкой;
- пытается выставить «Кто может комментировать» = «Все пользователи»;
- если комментарии не удалось переключить, **не останавливает** dry-run и пишет в
  общий `worker.log` строку с префиксом `!!! DZEN:`;
- ждёт состояния «Загрузили и обработали видео» и активной кнопки
  «Опубликовать»;
- сохраняет diagnostic screenshot и статус `READY_TO_PUBLISH`;
- **не нажимает «Опубликовать»**.

Повторный запуск для уже сохранённого `READY_TO_PUBLISH` draft не создаёт новый
черновик, а открывает существующий URL и повторно проверяет готовность.

## Текущие значения по умолчанию

Пока отдельный config contract не промотирован, helper имеет безопасные defaults,
которые можно переопределить локальным объектом `dzenUpload` в `config.json`:

```json
{
  "dzenUpload": {
    "enabled": false,
    "studioUrl": "https://dzen.ru/profile/editor/create",
    "channelName": "Заметки из подпространства",
    "seriesUrl": "https://dzen.ru/suite/7971db4c-2a4e-449f-b8bf-c3907486d6f1",
    "tags": ["ии", "ai", "полезныесоветы", "будущее", "лайфхак"],
    "commentsAudience": "Все пользователи",
    "processingTimeoutMs": 300000
  }
}
```

`enabled=false` специально сохраняется: этот PR не подключает публикацию в
Планировщик и не меняет обычный запуск NotebookLM worker. Явный `--dry-run`
разрешён как операторский эксперимент даже при `enabled=false`.

## Формат метаданных

Название строится по дате выпуска:

```text
ИИ-Сводка на 27 августа 2026 | Подпишись, чтоб получать свежее!
```

Описание:

```text
Что происходит в мире Искусственного Интеллекта (ИИ, AI) и Нейросетей на текущий момент - коротенько о самом главном

Без рекламы и воды на 27.08.2026:
- Глобальные новости
- Новости ИИ России
- Выводы и тренды

Этот выпуск:
https://rybalka.one/posts/2026-08-27/
https://dzen.ru/suite/7971db4c-2a4e-449f-b8bf-c3907486d6f1
```

Дата и URL выпуска берутся из выбранного job, а не зашиваются на 27 августа.

## Ручной запуск эксперимента

До promotion новые helper-файлы нужно положить рядом с `config.json` в локальный
NotebookLMBot. Затем:

```cmd
cd /d C:\TRASH\NotebookLMBot
run-dzen-dry-run.cmd --date=2026-08-27
```

Или напрямую:

```cmd
node dzen-publish.js --dry-run --date=2026-08-27
```

Если `--date` не указан, используется текущая дата по `timeZone`.

Для ручного входа и диагностики добавлен `open-robot-browser.cmd`. Он читает
существующий `config.json` и запускает тот же защищённый профиль с тем же CDP.

## Критерии успешного первого автоматического теста

Успех означает одновременно:

- существующий локальный MP4 выбран без Проводника Windows;
- создан/восстановлен один video draft;
- title и description полностью совпали с ожидаемыми;
- пользовательский PNG появился среди обложек;
- подтверждены все пять tag-chip;
- попытка выставить «Все пользователи» выполнена, а отклонение при необходимости
  записано как `!!! DZEN:` без остановки;
- Дзен завершил обработку и активировал «Опубликовать»;
- в `state.json` сохранён `READY_TO_PUBLISH` и `videoEditorPublicationId`;
- финальная кнопка не нажата.

Только после живой проверки этого dry-run отдельным изменением можно добавлять
финальный click, проверку опубликованного URL/раздела «Видео» и подключение этапа
к обычному локальному worker flow.
